# Install Budly Sales on CCCultivate

## WordPress

1. In WordPress, open **Plugins → Add New → Upload Plugin**.
2. Upload `budly-sales-agent.zip` and activate it.
3. Activation creates two published pages: **Ask Budly** and **Customer Policies**.
4. Open both pages once and confirm the theme layout looks correct.
5. Add **Ask Budly** to the main navigation and test one normal product journey and one support handoff.
6. Confirm the handoff arrives at `budlysupport@gmail.com`. WordPress uses its built-in mail function; if delivery fails, configure the host's free SMTP option or Gmail SMTP.

The plugin reads current WooCommerce names, prices, stock, variants, and links from the store's public API. It uses a 32-product allowlist and does not repeat medical marketing claims.

## Wix

Use either of these zero-cost options:

- Add an **Ask Budly** button on `wakenbakelounge.com` linking to the WordPress Ask Budly page. This is the recommended first launch.
- After the WordPress page is live and tested, embed its URL in a Wix HTML iframe. Linking is usually more reliable on mobile and avoids third-party-cookie or iframe restrictions.

## Acceptance check

- Consumer wellness produces a product card without a medical claim.
- Culinary excludes educational courses unless the shopper asks to learn.
- Books/courses offers the matching educational product.
- NFT membership shows price and a policy link without investment language.
- Website-listed wholesale items may be viewed; custom needs send a support handoff.
- Support email contains customer name, email, journey, summary, and reference.
- Customer Policies shows the July 17, 2026 approved rules.
