# Budly v1.8.0 Release Candidate Notes

Status: non-deployed release candidate; production activation is not authorized.

Budly v1.8.0 adds an optional governed natural-language conversation path. WordPress retains browser security, deterministic commercial and safety authority, and the guided fallback. A separately hosted Python/BROS runtime provides current-session conversation, approved `knowledge.retrieve`, the versioned Budly personality, OpenAI Responses API model execution, and structured response validation.

Production-safe defaults keep the conversational feature off and durable customer memory off. This release adds no production database migration and does not enable TG-P05A, TG-P05B, or TG-P06 in the production conversation path.

Application version: 1.8.0. Schema remains 1.5.0. Rules remain `bros-rules-1.5.0.0`. Commerce configuration remains `commerce-attribution-1.6.0.0`.
