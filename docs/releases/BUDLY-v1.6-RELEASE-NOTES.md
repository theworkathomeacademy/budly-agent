# Budly v1.6 Release Notes

Budly v1.6 adds a governed WooCommerce commerce-evidence layer without changing the customer experience. Verified server-side order events drive replay-safe attribution and currency-separated revenue reporting. Refunds are recorded as verified deltas; cancellations and failed post-payment orders reverse recognized commercial totals; identity conflicts enter review; and clicks or browser claims never establish revenue. Protected, nonce-checked, rate-limited CSV reporting exports only minimized aggregate data. Schema 1.4.0 is additive; customer-facing rules remain `bros-rules-1.5.0.0`. Gate F and production deployment remain blocked.
