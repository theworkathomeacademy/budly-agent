# Budly v1.7.1 Release Notes

Budly v1.7.1 is a bounded stabilization patch for the live v1.7 lineage. It prevents protected v1.7 REST handlers from substituting a default customer identity, replaces literal administration measurements with authoritative database aggregates, enforces the approved lifecycle sequence, aligns bounded PHP adaptive-question behavior with the approved v1.7 reference, and permanently tests the Bootstrap module-loader correction.
