# Budly v1.3.4-R1 release notes

R1 reconciles the accepted Git implementation with the historical production-facing package. It restores the dedicated Ask Budly page template, bounded page repair, verified avatar and mascot assets, and the production presentation while retaining the accepted Secure Memory, consent, session, governed-decision, safe-no-match, escalation, audit, and administration controls.

The historical client-side recommender, legacy public recall endpoints, and identity-bearing public analytics remain superseded. R1 adds a deterministic Git-native release builder and reconciliation acceptance tests. It introduces no database or rules migration and does not begin v1.4.
