# Budly v1.4 Release Notes

Budly v1.4 adds the engineering platform for reliable later releases: pull-request CI, repository and version policy, PHP and JavaScript validation, deterministic plugin packaging, source/file manifests, checksum generation, artifact retention, and a human-controlled release workflow.

Application metadata is 1.4.0. Schema 1.2.0 and rules `bros-rules-1.3.4.1` are unchanged. All accepted v1.3.4-R1 customer behavior, Secure Memory, decision evidence, production template, and visual assets are preserved. No customer-facing feature, production deployment, or future-version capability is included.
