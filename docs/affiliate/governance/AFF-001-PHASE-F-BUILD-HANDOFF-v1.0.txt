1. PURPOSE

Phase F creates the explicit boundary between SPECIFICATION and TECHNICAL BUILD.

The purpose is to determine exactly what an authorized implementation agent may build, what existing systems must be preserved, what must first be reconciled, how implementation will be sequenced, how success will be tested, what evidence must be returned, and where execution must stop.

Phase F exists specifically to prevent accidental production implementation, developers inventing policy, rebuilding existing capabilities, destroying proven infrastructure, coding against stale branches, uncontrolled migrations, premature deployment, and premature private-pilot activation.

The governing sequence remains:

ANALYZE → RECOMMEND → d-mac DECIDES → AUTHORIZED EXECUTION → VERIFY → REPORT
