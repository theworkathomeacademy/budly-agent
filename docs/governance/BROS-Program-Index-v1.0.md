## 1. Purpose
The BROS Program Index is the authoritative catalog of all constitutional, architectural, commercial, implementation, governance, and operational documents within the Budly ecosystem.
Its purpose is to:

- Identify every governing document.
- Establish each document’s authority.
- Define relationships between documents.
- Track ratification status.
- Record current versions.
- Identify the official Source of Truth.
- Support onboarding of architects, engineers, AI systems, and future contributors.
- Prevent duplicate documentation.
- Preserve long-term continuity.

This document is an index only.
It does not replace any governing document.

## 2. Authority Hierarchy
The BROS documentation hierarchy is:

1. BROS Constitution
2. BROS Foundation Library
3. Technical Blueprint
4. Commercial Constitution
5. Commercial Playbook
6. Architecture Decision Records (ADR)
7. Approved Policies
8. Approved Procedures
9. Implementation Specifications
10. Build Packages
11. Operational Reports
12. Working Notes (non-authoritative)

No lower-level artifact may override a higher authority.

## 3. Source of Truth
The official Source of Truth for all ratified documents is:
Google Drive Project Repository
Working conversations, drafts, temporary notes, AI chats, and implementation discussions are not authoritative until incorporated into the Source of Truth.

## 11. Operating Rules
Every future architect, engineer, AI system, consultant, or contributor shall:

1. Read the Program Index first.
2. Identify governing authority.
3. Confirm the latest ratified version.
4. Review dependent documents.
5. Avoid creating duplicate governance.
6. Preserve constitutional hierarchy.
7. Record any approved amendments.

No implementation work shall rely solely on conversation history when a ratified document exists.
